# Autonomous-sailing-boat_DQN
unity, ml agents, DQN, PPO

# Simulation environment conditions
1. random wind direction and random wind power
2. buoyancy consisting of four particles

# setting commend
1. check python version for support and download correct version : https://www.python.org/downloads/
2. move to project folder and make python virtual env : py -m venv venv
3. start venv : (inside the current project folder) venv\Scripts\activate
4. upgrade latest pip version : py -m pip install --upgrade pip
5. installing pytorch with CUDA : follow the url -> https://pytorch.org/get-started/locally/
6. intall mlagents : pip install mlagents
7. verify mlagents running : mlagents-learn --help
